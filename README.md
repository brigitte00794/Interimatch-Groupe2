# Interimatch-Groupe2
InteriMatch — Groupe 2 Plateforme web de mise en relation entre entreprises logistiques et intérimaires qualifiés, basée sur un système de matching par compétences, CACES, disponibilité et localisation.
InteriMatch est un projet réalisé par le Groupe 2, composé de 4 membres.
L’objectif est de concevoir une plateforme web spécialisée dans l’intérim logistique permettant de mettre rapidement en relation des entreprises ayant des besoins ponctuels avec des intérimaires disponibles et qualifiés.

La plateforme permet notamment :

- aux entreprises de créer et gérer des missions ;
- aux intérimaires de créer un profil avec leurs compétences, CACES, disponibilités et zone géographique ;
- de calculer un score de matching entre une mission et les profils disponibles ;
- de gérer les candidatures ;
- d’exploiter des données publiques issues de France Travail ;
- d’automatiser certaines actions avec n8n, comme les notifications ou les relances.
